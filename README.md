# Brew & Bloom Café — Web Technology Assignment 1

A responsive, multi-page café website made with HTML5, CSS3 and vanilla JavaScript.

## Pages
- `index.html` — Home / hero section and café highlights
- `menu.html` — Menu table with 8+ rows, `thead`, `tbody`, `rowspan` and `colspan`
- `gallery.html` — Six images, audio player and clickable image lightbox
- `booking.html` — Booking/enquiry form, validation and embedded Google Map

## Features
- Shared external stylesheet (`css/style.css`)
- Semantic HTML5 elements (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Responsive layout with CSS Grid, Flexbox and media queries
- Active navigation link on every page
- Dark / light theme toggle persisted in `localStorage`
- Mobile hamburger navigation
- Form with text, email, telephone, date, time, number, select, radio, checkbox and textarea inputs
- Built-in form validation with `required`, `pattern`, `min`, `max`, `minlength` and `maxlength`
- Gallery lightbox, audio controls, embedded map, print-friendly menu
- Accessible labels, image alt text and status messages

## Run locally
1. Download and extract the project ZIP.
2. Open the `webtech_cafe_website` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Internet access is required for remote Unsplash images, Google Fonts, the audio sample and embedded map.

## Deploy
Push the project folder to a GitHub repository. Import that repository into Vercel or Netlify and deploy the static site. The entry page is `index.html`.
